# Blinkit Sales Analysis Dashboard

## Overview

This project presents an interactive Power BI dashboard developed to analyze Blinkit's sales performance across different outlet locations, outlet sizes, product categories, and outlet types. The dashboard enables data-driven decision-making by providing key business insights through visual analytics and performance metrics.

## Objectives

* Analyze overall sales performance and customer ratings.
* Identify top-performing product categories.
* Compare sales across different outlet locations and outlet sizes.
* Evaluate the performance of various outlet types.
* Provide actionable insights through interactive visualizations.

## Tools & Technologies

* Power BI
* Power Query
* Microsoft Excel
* Data Analysis
* Data Visualization

## Key Performance Indicators (KPIs)

| Metric          | Value    |
| --------------- | -------- |
| Total Sales     | $219.87K |
| Average Sales   | $141.03  |
| Number of Items | 1,559    |
| Average Rating  | 4.35     |

## Dashboard Features

### Sales Performance Overview

Displays overall business performance using KPI cards for total sales, average sales, item count, and average customer rating.

### Outlet Establishment Analysis

Visualizes sales trends across outlet establishment years to identify growth patterns and business performance over time.

### Outlet Size Analysis

Analyzes sales contribution from different outlet sizes (Small, Medium, and High).

### Outlet Location Analysis

Compares sales generated across Tier 1, Tier 2, and Tier 3 locations.

### Product Category Analysis

Evaluates sales performance across various product categories such as:

* Snack Foods
* Fruits and Vegetables
* Household Items
* Frozen Foods
* Dairy Products
* Beverages
* Health and Hygiene Products

### Fat Content Analysis

Compares sales generated by products with different fat content categories.

### Outlet Type Comparison

Analyzes key metrics such as:

* Total Sales
* Number of Items Sold
* Average Sales
* Average Rating
* Item Visibility

across different outlet types.

## Key Insights

* Tier 3 outlets generated the highest overall sales.
* Medium-sized outlets contributed the largest share of revenue.
* Snack Foods and Fruits & Vegetables were among the top-performing product categories.
* Supermarket Type 1 recorded the highest total sales and item count.
* The average customer rating remained consistently high at 4.35, indicating positive customer satisfaction.

## Conclusion

The dashboard provides a comprehensive view of Blinkit's sales performance and customer trends. Through interactive visualizations and business-focused KPIs, the project demonstrates how Power BI can be used to transform raw data into meaningful insights that support strategic decision-making.
